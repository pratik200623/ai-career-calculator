# AI Career Calculator

This repository contains a Python script to help users calculate their potential career growth based on their current skills and experience.

## Features
- Calculate career growth based on current skills
- Provide personalized career advice
- Track progress over time

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/pratik200623/ai-career-calculator.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
1. Run the script:
   ```bash
   python career_calculator.py
   ```
